## MASLA: Extender pe connect hai, kabhi chal jata hai —
##         jab "Connected, no internet" / net slow ho to software band

Asli wajah (software bug nahi):
  Android WiFi ko "no internet" samajhta hai
  → traffic Mobile Data (4G) pe bhej deta hai
  → 192.168.1.105 LAN IP nahi milta
  → Order Taker "kaam nahi karta"

### TABLET pe turant fix (har device)
1. Mobile Data OFF (Order Taker use karte waqt)
2. Wi‑Fi → Intelligent Wi‑Fi / Auto switch to mobile data → OFF
3. Best: Airplane Mode ON, phir sirf Wi‑Fi ON
4. Guest WiFi se connect na ho

### PC pe strong fix (optional — Admin)
1. scripts\start-cafe-captive-dns.bat  (window OPEN rehne do)
2. Router DHCP DNS = 192.168.1.105
   (Primary DNS = cafe PC)
Phir Android local check se "internet OK" maan lega — SIM pe switch nahi karega.
