## Error: ERR_ADDRESS_UNREACHABLE / site can't be reached

Matlab: tablet WiFi se server Ethernet tak pahunch nahi sakti.
Asli wajah aksar:
  - Extender / router AP Isolation ON
  - Guest WiFi
  - Server cable router pe, tablet extender pe (alag "bubble")

## PERMANENT FIX (ek baar karo — roz ka masla khatam)

### Option A (best — 2 minute)
1. Server PC ka Ethernet cable ROUTER se NIKALO
2. Wahi cable EXTENDER ke LAN port mein LAGAO
   (WAN / Internet port NAHI — LAN port)
3. PC 10 sec wait / restart
4. Tablet par kholo:
   http://192.168.1.105/lan-test.html
5. Pass ho to:
   http://192.168.1.105/order-taker

### Option B
Router (192.168.1.1) + dono extenders:
  - AP Isolation / Client Isolation = OFF
  - Guest WiFi = OFF
  - Allow wireless devices to access wired LAN = ON

### Option C
Server PC pe USB WiFi dongle — same WiFi jisme tablets hain.
